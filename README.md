# LingBox-PlayBridge

游桥 PlayBridge，面向灵匣 LingBox 的双端远程游戏插件。

当前处于私有开发和仓库初始化阶段。原生 RdpGames 源码尚未导入本仓库，插件适配与游戏模式尚未实现，也没有可安装的插件发布包。

## 计划实现的体验

1. 控制电脑与被控电脑都安装 LingBox 和同一版本的 LingBox-PlayBridge。
2. 用户使用 Windows 远程桌面 `mstsc.exe` 建立连接，并在两端首次选择各自角色。
3. 插件通过现有 RDP 通道配对并同步状态，不另建远程桌面服务或云端中继。
4. 用户明确开启游戏模式后，两端协调保护辅助功能快捷键，减少连续按 Shift 等操作触发系统提示的干扰。
5. 停止游戏模式或连接失效时恢复各端原设置；异常退出后提供下次启动恢复机制。

首次安装或更新 RDP 通道组件后，可能需要用户重新打开 mstsc。插件不会自动断开现有远程会话。

## 技术方向

- 复用原生 RdpGames 的窗口识别、相对鼠标、输入 worker 和 RDP 虚拟通道。
- 新增 MCP stdio 适配器，让 LingBox 管理原生助手的启动、状态和停止。
- 使用独立管理 IPC，不把现有 mstsc 桥接管道改作通用控制接口。
- 游戏模式分别保存两端各自的设置快照，只修改必要的快捷键标志；已启用的辅助功能保留，并报告保护范围。
- 首版制作同一份 Windows x64 自包含插件 ZIP，供两端安装。

这里描述的是目标设计，不代表上述新增功能已经交付。阶段范围及验收见 [开发路线](docs/ROADMAP.md)。

## 下载与许可

本仓库目前为私有仓库，只有获得仓库权限的账号能够访问。首次可安装版本完成后，计划通过 GitHub Releases 分发插件包；公开下载需要另行确认仓库或分发渠道的公开安排。

本仓库尚未选择开源许可证。导入原生项目及第三方依赖前，需要核对其来源和许可，保留必要的版权与许可证文件；计划公开发布不等于已经取得重新许可的权利。
